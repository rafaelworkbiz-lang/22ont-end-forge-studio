# Conectar o projeto ao GitHub

## Limitação importante
A sincronização do Lovable com o GitHub **não consegue se ligar a um repositório que já existe**, como `rafaelworkbiz-lang/MERCADOLIVRE2`. Ela sempre cria um repositório **novo e privado** na sua conta. Eu também não consigo fazer essa conexão por você: ela exige sua autorização no GitHub.

## Passo a passo (você faz, leva 1 minuto)
1. Você já está na tela **Git**. Clique em **Conectar GitHub** e autorize o Lovable na conta `rafaelworkbiz-lang`.
2. Escolha a conta e confirme a criação do repositório novo.
3. O código inteiro é enviado automaticamente; daqui pra frente, cada mudança vai sozinha.

## E o repositório MERCADOLIVRE2?
Opções depois de conectar:
- **Deixar de usar** o MERCADOLIVRE2 e passar a usar o repositório novo (mais simples).
- Ou, se quiser o código lá também, copiar manualmente pelo GitHub (baixar do novo e enviar ao antigo) — mas ele não ficará sincronizado.

## O que eu faço
Nada no código muda. Depois que você conectar, me avise e eu confirmo se a sincronização está funcionando.
